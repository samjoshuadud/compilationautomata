PROBLEM
1. Compute all the terms of the Fibonacci numbers. This page is the Fibonacci option (separate HTML instead of a menu).
Valid input is greater than 2.
Recursive definition
F(0) = 0
F(1) = 1
F(n) = F(n - 1) + F(n - 2), for n >= 2
Sequence rule
0, 1, 1, 2, 3, 5, 8, 13, 21, ...
Each term is the sum of the previous two terms.
SAMPLE OUTPUTS
SAMPLE OUTPUT 1: This program will find all the terms of the Fibonacci numbers. Input the number of terms: 5 The Fibonacci numbers are: 0, 1, 1, 2, 3
