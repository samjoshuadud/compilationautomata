Tribonacci Numbers

Generate the Tribonacci sequence where each term is the sum of the previous three.

PROBLEM
1. Compute all the terms of the Tribonacci numbers. This page is the Tribonacci option.
Valid input is greater than 3.
Recursive definition
T0 = 0
T1 = 0
T2 = 1
Tn = Tn−1 + Tn−2 + Tn−3, for n ≥ 3
Sequence rule
0, 0, 1, 1, 2, 4, 7, 13, 24, ...
Each term is the sum of the previous three terms.
Tribonacci starts with 0, 0, 1. Each next term is the sum of the previous three terms: T(n) = T(n - 1) + T(n - 2) + T(n - 3).
